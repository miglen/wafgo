# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/), and the project aims to follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Published multi-arch Docker image `miglen/wafgo` (linux/amd64, linux/arm64) on Docker Hub.
- Add a wafgo banner to the README.

### Fixed
- Preserve existing report files when saving fails, and report CLI output
  failures through the exit status, including short writes and file-close errors.
- Reject trailing data and read errors after a JSON target array.
- Correct binary download instructions to point to release workflow artifacts.
- Initialize plugin registry caches safely under concurrent access and return
  independent slices to callers.
- Copy engine headers on construction and return independent header snapshots.
- Report target failures on stderr when result records are written to stdout.

### Changed
- `WriteRecords` requires a supported format; library callers must pass
  `FormatText` explicitly instead of relying on an empty or invalid format.
- New report files use owner-only permissions (`0600`). Replacements retain
  existing permission bits; symbolic links and special output files are rejected.
- Restrict CI and release workflow tokens to read-only repository permissions
  and exclude common credential files from Docker build contexts.
- Add pinned lint checks and align the Go toolchain across local builds, CI,
  releases, and Docker.
- Clarify API ownership comments, examples, and the scope of parity tests.

## [0.1.0]

Initial release — a fast Go port of [wafw00f](https://github.com/EnableSecurity/wafw00f).

### Added
- WAF/CDN fingerprinting with 172 wafw00f signatures (auto-generated from the
  upstream Python plugins) plus 92 signatures from nuclei-templates
  `waf-detect`, de-duplicated by product (264 total).
- Parity test suite: thousands of cases generated by running the original
  Python plugins, replayed against the Go signatures for identical results.
- Concurrent probing per target and parallel multi-target scanning (`-c`).
- Enforcement verdict distinguishing an actively-blocking WAF from a WAF/CDN
  merely in path (e.g. Cloudflare as a CDN).
- Generic (behavioural) detection, mirroring wafw00f.
- Origin-IP discovery (`-O`): DNS, crt.sh, common origin subdomains, optional
  Shodan/Censys, and `--origins-active` direct-connect confirmation.
- Bypass reference (`-X`): evasion technique catalog and documented per-WAF
  bypasses citing public research.
- Active bypass fuzzer (`--fuzz`, gated by `--authorized-test`): sends tampered
  payloads and reports which bypass the WAF.
- wafw00f-compatible CLI and JSON/CSV/text output; file and stdin input.
- `scratch`-based container image, Makefile, GitHub Actions CI and release.
